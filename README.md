# 一心日志

给两个人用的微信小程序。这一轮能用的是：微信登录、互相确认对象、女性经期、排卵和易孕期推算、纪念日、小日程、首页天气和穿衣提醒。其余入口只显示「施工中」。

不发布正式版。只有管理员、项目成员和体验成员能打开体验版。

## 打开之前

1. 用微信开发者工具打开本目录。云环境 ID 已写在 `miniprogram/app.js`：`ydsglog-d0gvifdry2da871a2`。
2. 在 `cloudfunctions/api` 上右键，选择「上传并部署：云端安装依赖」。
3. 开发者工具顶部点「云开发」，进入「数据库」。四个集合要等小程序第一次成功调用云函数后才会出现。点进某个集合，打开「数据权限」或「权限设置」，选「仅管理端可读写」。如果列表里没有这句，选「所有用户不可读写」，效果相同：小程序页面不能直接碰数据库，只有云函数能读写。
4. 体验版不在开发者工具的设置里。先点开发者工具右上角「上传」，填写版本号。再用浏览器打开 [mp.weixin.qq.com](https://mp.weixin.qq.com)，进入「管理 → 版本管理 → 开发版本」，把刚上传的版本「选为体验版」。添加对方在「管理 → 成员管理」，页面下半部分的「体验成员」。不要点「提交审核」或「发布」。你自己用开发者工具的「预览」就能在手机上看，不必先加自己为体验成员。
5. 公众平台「服务器域名」这一页先不用填。微信没有官方天气接口，天气由云函数去查，小程序自己不访问外网。
6. 在「用户隐私保护指引」里说明：位置只用于查询当地天气，不保存，也不给对方看。

## 页面

- 首页：当地天气、穿衣建议、经期提醒，以及还在施工中的入口。
- 日历：格子里只有图标。筛选只影响图标，记在本机，并按微信分开。下滑超过一段距离才看到最近 30 天。
- 我的：昵称、性别、周期设置、确认对象。

经期记在女性名下。双方互为对象后，男方自己的月历上能看到，也能修改她的经期。纪念日和日程默认双方可见，创建或编辑时可以改成仅自己可见。

## 云函数

`cloudfunctions/api` 按 `action` 处理登录、资料、对象、经期、纪念日、日程和天气。身份使用云函数拿到的 openid，不信任前端传来的身份。
